# -rk3568-safety-terminal-public
 系统集成 SHT30 温湿度传感器、BH1750 光照传感器、LD2410 毫米波雷达、门磁和 USB 摄像头，通过 Linux 驱动、设备树、V4L2、RKNN、Qt/QML 和用户态服务完成数据采集、状态判断、告警联动、HMI 展示、   SQLite 记录及 MQTT 事件上报。    项目重点展示：    - RK3568 Linux 设备树与驱动开发   - 字符设备事件接口与用户态通信   - I2C、UART、GPIO、PWM、V4L2 外设接入   - RKNN 目标检测与 ROI 入侵告警   - Qt/QML HMI 实时监控与历史记录   - SQLite 事件持久化和 MQTT 消息上报   - 30 FPS 视频预览与独立 AI 推理链路
